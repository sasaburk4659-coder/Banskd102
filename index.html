Telegram Mini App

Безопасная авторизация по email с кодом подтверждения

🚀 Открыть приложение 📖 Узнать больше

✨ Основные возможности

✉️

Email авторизация

Простая и безопасная авторизация через электронную почту с проверкой кода подтверждения.

🔐

Код подтверждения

Автоматическая отправка 6-значного кода на email с ограничением по времени (10 минут).

💾

Локальное хранилище

Все данные сохраняются локально в браузере без необходимости в сложной базе данных.

📱

Адаптивный дизайн

Идеально работает на всех устройствах: смартфонах, планшетах и компьютерах.

🎨

Современный UI

Красивый и интуитивный интерфейс с плавными анимациями и переходами.

⚡

Быстрая загрузка

Минимальные зависимости, быстрая загрузка и работа приложения даже на медленных сетях.

📺 Три экрана приложения

Экран 1: Вход
✉️

Введите email

Введите вашу электронную почту для начала процесса авторизации. Например: sasaburk4659@gmail.com

Экран 2: Подтверждение
🔐

Введите код

Введите 6-значный код подтверждения, который был отправлен на вашу электронную почту.

Экран 3: Главная
👤

Добро пожаловать!

Страница пока пуста. Здесь будет ваш контент. Кнопка выхода для сброса сессии.
