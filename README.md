# 📱 Telegram Mini App - Email Authentication System

Полнофункциональное Telegram Mini App приложение с авторизацией по email и кодом подтверждения.

## 🌟 Основные возможности

- ✉️ **Email авторизация** - Простая и безопасная авторизация через электронную почту
- 🔐 **Код подтверждения** - Автоматическая отправка 6-значного кода на email
- 💾 **Локальное хранилище** - Все данные сохраняются в браузере
- 📱 **Адаптивный дизайн** - Работает на всех устройствах
- 🎨 **Современный UI** - Красивый интерфейс с анимациями
- ⚡ **Быстрая загрузка** - Минимальные зависимости

## 🎯 Три экрана приложения

### Экран 1: Ввод Email
Пользователь вводит свою электронную почту (например: `sasaburk4659@gmail.com`).

### Экран 2: Ввод Кода
Пользователь вводит 6-значный код подтверждения, отправленный на email.

### Экран 3: Главная страница
Страница с информацией о входе и кнопкой выхода. Пока пуста, готова к расширению.

## 🚀 Быстрый старт

### Локальное тестирование

1. Откройте `app.html` в браузере
2. Введите email
3. Нажмите "Далее"
4. Введите код подтверждения
5. Готово!

### На GitHub Pages

1. Форкните этот репозиторий
2. Перейдите в Settings → Pages
3. Выберите "Deploy from a branch"
4. Выберите ветку "main"
5. GitHub Pages развернет приложение автоматически

### На Vercel

1. Импортируйте репозиторий на [vercel.com](https://vercel.com)
2. Vercel автоматически развернет приложение
3. Получите постоянный URL

## 📚 API Endpoints

### POST /api/send-code
Отправить код подтверждения на email

```json
{
  "email": "user@example.com"
}
```

### POST /api/verify-code
Проверить код подтверждения

```json
{
  "email": "user@example.com",
  "code": "123456"
}
```

## 🎓 Как интегрировать с Telegram Bot

1. Создайте бота в `@BotFather`
2. Получите токен бота
3. Настройте Menu Button с URL приложения
4. Откройте приложение в Telegram

Подробные инструкции см. в `docs.html`.
